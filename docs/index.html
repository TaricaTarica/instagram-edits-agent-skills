What the agent does

Edits for Mac gives agents the tools (274 of them). These 14 skills give them the craft: what to cut, how long a hook should stay on screen, where captions are safe from Instagram's UI, how loud a Reel should be, and in which order to do it all.

edits-reel

Runs the whole pipeline with approval checkpoints.

edits-rough-cut

Cuts silences and filler words at word level.

edits-hook

Builds the first 3 seconds, a cold open and hook text.

edits-captions

Adds auto captions in 39 styles, keeps them in the safe zone and emphasizes keywords.

edits-polish

Adds punch-ins, face-aware zooms, B-roll and sound effects.

edits-audio

Cleans noise, normalizes to −14 LUFS and ducks music under voice.

edits-color

Fixes exposure, white balance and skin, applies LUTs and matches cameras.

edits-montage

Cuts to the beat, detects shots and adds speed ramps.

edits-clip-pick

Finds the best 15–55 s moments in podcasts and lives.

edits-cover

Picks the best frame for the cover and keeps it safe for the 3:4 grid.

edits-variants

Makes Trial Reel versions for A/B tests.

edits-qa

Reviews frames, exports and validates the file.

edits-style-learn

Learns a creator's style from reference Reels.

edits-operate

Handles setup, tool discovery and troubleshooting.

Tested end to end: a 34 s raw take became a cut, captioned, color-graded Reel at −14 LUFS, exported at 1080×1920 with every QA check passing, in about 16 minutes of agent time.

How to connect Claude Code to Instagram Edits

  1. Install Edits for Mac (free, Apple silicon) and sign in.
  2. In Edits, open Settings → Automation → Enable Automation Server. It runs at http://127.0.0.1:19501/mcp.
  3. Under Connect an AI client, copy the command for Claude Code, Codex, Cursor or ChatGPT and run it in your terminal. Keep the token out of chats.
  4. Install the skills and start a new agent session:
npx skills add TaricaTarica/instagram-edits-agent-skills

Claude Code plugin instead:

/plugin marketplace add TaricaTarica/instagram-edits-agent-skills
/plugin install instagram-edits-agent-skills@instagram-edits-agent-skills

FAQ

How do I edit Instagram Reels with Claude?

Turn on the automation server in Edits for Mac, connect Claude Code, install these skills and ask "Edit this into a Reel in Edits." The edits-reel skill makes a plan, asks for your approval and runs the pipeline.

Is there a Claude skill or plugin for Instagram Edits?

Yes. This project is both a Claude Code plugin and a set of open Agent Skills (SKILL.md) for Instagram Edits for Mac.

Does Instagram Edits have an API or MCP server?

There is no public API, but Edits for Mac includes a local MCP automation server (Settings → Automation) that agents can use.

Can I use Codex, Cursor or ChatGPT with Edits?

Yes. Edits shows connect commands for all of them, and the skills follow the open Agent Skills format.

Can Claude post or schedule my Reels?

No. The automation server has no publishing tool. The agent prepares the project and the export; you post from Edits.

Does it work on Windows or iPhone?

No. The automation server exists only in Edits for Mac (Apple silicon).
